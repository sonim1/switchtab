How to switch between apps and windows on Mac

Use Command + Tab to switch apps. Use Command + ` (backtick) to switch windows in the app you are using. The difference matters when one app has several open windows.

For example, Safari is one app, but two separate Safari windows are two destinations. Command-Tab selects Safari; the window shortcut moves between its windows. Browser tabs are a separate level of navigation.

Mac's built-in switching shortcuts

App switching and window switching are different actions.
ShortcutWhat it selects
Command + TabA different open app. Hold Command and tap Tab until the app you want is selected.
Command + Shift + TabThe previous app in the app switcher.
Command + `Another window in the current app. The ` symbol is the grave accent, also called backtick.

You do not need an extra app to use these shortcuts. Key placement and window-shortcut labels can vary with your keyboard layout. Check System Settings > Keyboard > Keyboard Shortcuts if your layout differs.

Apple documents the built-in behavior in See your open windows on Mac.

When a macOS window switcher helps

Built-in app switching works well when choosing an app is enough. If you keep several documents or windows in the same app, a window list can help you choose the destination before bringing it forward.

SwitchTab is a free, open-source Command-Tab alternative for macOS 14 or later. It combines an app switcher with a current-app window switcher. Window titles identify each destination, and optional previews show its contents.

SwitchTab is for switching focus, not tiling or resizing windows. Its window list includes standard, visible, non-minimized windows; it does not promise to list every full-screen, hidden, or minimized window.

Switch from an app to a specific window

With both SwitchTab modes enabled and their default shortcuts registered:

  1. Hold Command and press Tab to open the application switcher.
  2. Keep holding Command and tap Tab to highlight the app you want. Add Shift to move backward.
  3. Still holding Command, press backtick (`) to show the highlighted app's windows.
  4. Tap backtick to cycle windows, then release Command to focus the selected window.

Press Escape before releasing Command to cancel. You can also click a destination to confirm it. To switch windows in the current app directly, start with Command-Backtick.

If a shortcut or preview does not work

Command-Tab still opens the macOS switcher

Check that application switching is enabled in SwitchTab's shortcut settings and that Accessibility permission is granted. Upgrades can preserve an earlier disabled setting. If interception cannot be installed, SwitchTab leaves the native shortcut working and shows registration guidance.

Command-Backtick cannot be registered

macOS can reserve this shortcut. SwitchTab can use Option-Control-Backtick as a fallback, or you can choose another shortcut in Settings. The steps above describe the default key assignments.

Window previews are missing

Screen Recording permission is optional and enables previews. Without it, switching still works with window titles and placeholders. Accessibility permission is required to discover and focus windows. An individual preview can also be unavailable even when permission is granted.

How do I get the native switcher back?

Disable application switching in SwitchTab's settings or quit SwitchTab. Command-Tab returns to macOS.

Install SwitchTab

SwitchTab requires macOS 14 or later. It is free, with no account, ads, subscription, or paid feature tier.

If you already use Homebrew, run:

brew install --cask sonim1/tap/switchtab

Otherwise, download the signed and notarized DMG, open it, and drag SwitchTab to Applications. Open the app and follow its permission guidance.
